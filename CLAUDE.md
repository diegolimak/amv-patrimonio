# Site AMV Patrimônio

## O projeto
Site institucional da AMV Patrimônio — consultoria patrimonial estratégica com foco em consórcio como ferramenta de construção de patrimônio.

## Arquivos principais
- `site.html` — site principal
- `comercial.html` — apresentação comercial interativa
- `planejamento.html` — planejamento estratégico interativo
- `cartao.html` — cartão de visita digital
- `manual.html` — manual da marca
- `assets/site.css` — estilos do site
- `assets/amv.css` — estilos compartilhados da marca
- `assets/deck-amv.css` — estilos dos decks/apresentações
- `assets/image-slot.js` — componente de imagem

## Identidade visual
- **Cor principal**: `#0D1B2A` (azul escuro profundo)
- **Dourado**: `#C9A84C` (ouro, usado em destaques e CTAs)
- **Símbolo**: diamante (losango com linhas internas)
- **Wordmark**: "AMV" em caixa alta + "Patrimônio" em peso leve
- **Tom**: sofisticado, confiável, estratégico — não é banco, é consultoria

## Tom de voz
- Direto e estratégico, nunca agressivo
- Fala com pessoas que querem construir patrimônio de verdade
- Posicionamento: consórcio é ferramenta inteligente, não produto de vendedor
- Evitar jargões financeiros complexos — clareza acima de tudo

## SEO — palavras-chave foco
- consórcio imobiliário
- consultoria patrimonial
- consórcio como investimento
- construir patrimônio
- AMV Patrimônio Brasília (ou região do cliente)

## O que ainda falta no site (oportunidades)
- Formulário de diagnóstico patrimonial funcional
- Blog / conteúdo orgânico
- Página de cases detalhados
- Integração com WhatsApp / CRM
- Versão mobile mais refinada
- Meta tags de SEO completas
- Google Analytics / Meta Pixel

## Como trabalhar aqui
- Sempre teste o resultado abrindo o HTML no navegador
- Mantenha a identidade visual consistente
- Qualquer nova seção deve seguir os padrões de cores e tipografia existentes
- Antes de alterar site.html, leia as primeiras 100 linhas para entender a estrutura
